# 🌎 React Hello World  

A minimal **React setup** using **CDN links**-no build tools, just pure React! 🚀  

## 📌 What’s Inside?  
- ✅ **Simple React Component** rendering a greeting message.  
- ✅ **No Build Tools Required** - Just open in a browser and run.  
- ✅ **Perfect for Beginners** - Learn React with minimal setup.  

## 🚀 How to Run  
1. Clone this repository:  
   ```sh
   git clone https://github.com/Zaheer2003/react-hello-world.git
   ```  
2. Open `index.html` in your browser.  

## 🛠️ Code Overview  
```jsx  
function HelloWorld() {
    return <h1>Hello World</h1>;
}

const { createRoot } = ReactDOM;
const root = createRoot(document.getElementById('root'));
root.render(<HelloWorld />);
```
